# Renta-Car

Rent-a-car şirkətləri üçün daxili flot idarəetmə sistemi.

## Stack

- React + Vite
- Tailwind CSS
- Firebase Realtime Database
- React Router

## Quraşdırma

```bash
npm install
npm run dev
```

## Struktur

- `/` — Maşınlar (status: boş / icarədə / servisdə)
- `/yeni-icare` — Yeni icarə qeydiyyatı
- `/teqvim` — Yaxınlaşan qayıdışlar
- `/admin` — Admin panel (logo-ya 5 dəfə toxunmaqla giriş) — maşın idarəetməsi, tam icarə siyahısı, hesabat, tənzimləmələr

## Giriş

Standart PIN-lər (ilk qurulumdan sonra Admin → Tənzimləmələr-dən dəyişin):

- İşçi ekranı: `1111`
- Admin panel: `2026`
